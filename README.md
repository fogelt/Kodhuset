# Umbraco – Accessibility-Focused Project

This project is built using [Umbraco CMS](https://umbraco.com/) with a focus on **web accessibility**. The goal is to create an accessible and user-friendly website that follows accessibility best practices.

## Getting Started

### Run the project

   ```bash
   dotnet run
   ```

### First-Time Setup

When you start the project for the first time, the Umbraco installation wizard is automatically served in your web browser.

Follow the installation guide to configure your Umbraco instance.

Once the installation is complete:

1. Create your Umbraco administrator account.
2. Log in to the Umbraco backoffice.
3. Start creating and managing website content.

## Accessibility

Accessibility is a key focus of this project. Development aims to follow accessibility best practices, including:

- Semantic HTML and meaningful page structure.
- Keyboard accessibility and navigation.
- Clear labels and accessible forms.
- Sufficient colour contrast.
- Screen reader compatibility.
- Consistent and predictable navigation.

The goal is to make the website usable and accessible to as many people as possible.
